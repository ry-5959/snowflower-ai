# 눈의꽃 AI — 대설 피해 예보와 점검 순서표

2026 AI 활용 전국 대학생 창업 해커톤(한림대, 11.19~20) 현장 제작 · 팀 한라 스마트 메이커즈

강원 읍면동 188곳의 대설 피해 위험을 실제 예보로 계산해, 지자체가 어디부터 점검할지 순서를 정해 주는 웹 도구입니다.

## 폴더

| 위치 | 내용 |
|---|---|
| `public/` | 화면(index.html, style.css, app.js), 데이터 묶음(data.js), 지도 라이브러리(lib/) |
| `netlify/edge-functions/ai.js` | Gemini 호출(주 경로) |
| `netlify/functions/ai.mjs` | Gemini 호출(예비 경로) |
| `netlify/functions/kma.mjs` | 기상청 단기예보 조회 |
| `netlify/edge-functions/tile.js` | 브이월드 항공사진·지명 타일 전달 |
| `netlify.toml` | Netlify 설정(빌드 과정 없음) |

## 키 (Netlify 환경변수에만 넣습니다. 이 저장소에는 키가 없습니다)

| 이름 | 값 |
|---|---|
| `GEMINI_API_KEY` | Google AI Studio에서 받은 Gemini 키 |
| `KMA_SERVICE_KEY` | 공공데이터포털 「기상청_단기예보 조회서비스」 인증키 |
| `VWORLD_KEY` | 브이월드(vworld.kr) 오픈API 인증키. 없으면 Sentinel-2 위성사진으로 표시 |
| `VWORLD_PUBLIC` | `yes`로 넣으면 브라우저가 브이월드에서 직접 타일을 받음(키가 방문자의 요청 주소에 보임). 서버 전달이 될 때는 필요 없음 |

키가 없어도 지도·예보·순서표·검증은 작동합니다. AI 문장은 규칙으로 만든 문장으로 바뀌고 화면에 그렇게 표시됩니다.

## 자료와 사용 조건

- 피해 기록: 행정안전부 국민재난안전포털 자연재난상황통계(대설, 강원, 2004~2024)
- 강설·특보: 기상청 기상자료개방포털 종관·방재 관측 일자료, 기상특보 이력
- 예보: Open-Meteo Forecast API (CC BY 4.0, 비상업 무료), 기상청 단기예보(공공데이터포털)
- 시설: 농림수산식품교육문화정보원 팜맵 통계(2025)
- 인구: 행정안전부 주민등록 인구통계(2026.10)
- 전통시장: 소상공인시장진흥공단 전국전통시장표준데이터
- 행정경계: admdongkor(vuski)
- 항공사진·도로·지명: 국토교통부 브이월드 WMTS(키 설정 시)
- 지도: MapLibre GL JS 5.24.1(BSD-3-Clause), AWS Terrain Tiles(Mapzen), Sentinel-2 cloudless 2016 by EOX(CC BY 4.0)

## 한계

- 피해 기록이 시군 단위라 읍면별 정답으로 검증하지 못했습니다.
- 학습은 관측소 자료, 예보는 격자 자료라 눈 무게가 다르게 나올 수 있습니다.
- 0℃ 안팎의 젖은 눈은 위험을 낮게 봅니다.

## 2026.11.19 밤 추가한 것

- 남은 눈 무게(지상 기준 추정): 전날 남은 무게 + 새 눈(강설일 강수량 1mm = ㎡당 1kg) − 녹은 양(일평균기온 1℃·하루 4mm, 가정). 지도 아래 "남은 눈 무게" 단추와 날짜 막대, 읍면 정보의 날짜별 막대그래프에서 본다.
  - 예보 화면: Open-Meteo 예보에 지난 14일을 함께 받아 이미 쌓인 눈부터 이어서 계산한다.
  - 과거 재현: 눈 그친 날의 값은 시군 관측 강수량(모델 입력과 같은 값)에서 시작하고, 그 뒤 기온은 Open-Meteo 과거 날씨(Historical Weather API, 재분석 자료)로 계산한다. 관측값이 아니라는 점을 화면에 적었다.
  - 한계: 지붕은 미끄러짐·난방으로 더 빨리 줄 수 있고, 녹는 속도는 가정값이다(추가 검증 필요).
- AI 답변·보고서·주민 안내 아래에 근거 한 줄(학습 건수, 교차검증 판별 정확도, 높음 이상 등급의 실제 피해 비율)을 화면이 직접 붙인다. 수치는 data.js의 모델 값에서 계산한다.
- 마우스 조작: 왼쪽 끌기 회전·기울이기, 휠 누르고 끌기 이동, 휠 굴리기 확대·축소. 터치 조작은 그대로.
